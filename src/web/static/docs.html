what coco does

everything below is configured per-server from the dashboard - no code editing needed.

moderation

warn, kick, ban and mute with configurable dm/channel messages. optional confirmation step before actions apply. mute log channel is set from the dashboard.

anti-raid

lockdown mode locks the server down on demand, with an option to also silence your member role.

tickets

post a ticket panel in any channel. staff role, category and the reason message are all configurable. threads/tickets open on click.

button containers

build custom button rows for any channel from JSON - open tickets, trigger actions, or link out - without redeploying the bot.

music & radio

queue youtube links, pause/resume/skip, and a radio mode for continuous playback. controllable from chat or the dashboard's action panel.

economy & color roles

a coin economy with chat and slash commands, plus self-serve color roles for members.

twitch integration

go-live announcements and twitch chat relay, backed by eventsub webhooks. needs a twitch app + webhook secret in your .env (see .env.example).

greetings & announcements

join/leave messages with {user} and {mention} placeholders, and an announcement channel with an optional ping role.

permissions

server admins always have full access. beyond that, permissions are granted per-role per-feature from within the server, not hardcoded - see permissions.py.
