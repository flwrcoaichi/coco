setting up ticketing

  1. make a channel or category for tickets to open in.
  2. run /ticket panel #channel - this posts the button members click to open a ticket.
  3. optional: set a staff role and category from the dashboard's tickets tab, so new tickets ping staff and land in the right category.
  4. staff can /ticket add @member to pull someone else into an open ticket, and /ticket close when it's done.

setting up color roles

  1. create whatever color roles you want members to be able to pick (name and color are up to you).
  2. members run /color and choose one - it swaps out any previous color role automatically.
  3. no dashboard config needed; it reads from your server's existing roles.
